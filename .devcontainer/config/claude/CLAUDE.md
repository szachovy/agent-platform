# Project Context and Guidelines

## Code Style

- Follow existing code conventions in the repository unless asked otherwise
- Write self-documenting code with clear variable and function names
- Avoid premature abstractions and over-engineering, follow coding principles like SOLID, KISS, etc.

## Communication Style

- Be concise and direct in responses
- Avoid unnecessary emojis unless explicitly requested
- Focus on technical accuracy over politeness
- Provide actionable feedback with specific file locations using [filename.ext:line](path) format

## Development Workflow

- Follow security rules defined in `/home/node/.claude/rules/security.md`
- Always read files before modifying them
- Use AskUserQuestion when requirements are unclear
- Break complex tasks into smaller, manageable steps
- Use TodoWrite to track multi-step tasks
- Mark todos as in_progress before starting work
- Complete todos immediately after finishing each task
- Ask for writing or running tests after making changes to verify functionality
- See `/home/node/.claude/TOOLS.md` for detailed guidance on when and how to use available tools
